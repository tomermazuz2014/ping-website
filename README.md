# PING — Marketing Website

אתר תדמית רשמי של PING: פלטפורמת קביעת תורים שמחברת בין לקוחות לעסקים.

- **Stack:** single self-contained `index.html` (HTML/CSS/vanilla JS), RTL Hebrew, no build step
- **Brand:** Tiffany `#81D8D0` · Porcelain `#F6F4EF` · Ink `#0E1A1A` · Ploni (Rubik fallback)
- **Hosting:** GitHub Pages — serves `index.html` from the repo root

## Local preview
Open `index.html` in a browser. No dependencies.
